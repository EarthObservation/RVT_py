# RVT domain glossary

- **Visualization**: a DEM-derived raster product (hillshade, sky-view factor, openness, local dominance, MSRM, MSTP, sky illumination…). Spelled "visualization" throughout — it is part of the library's name (Relief Visualization Toolbox) — as a deliberate exception to the otherwise-British spelling convention.
- **Config**: a frozen dataclass holding one visualization's parameters; its `compute` method produces the visualization from a DEM array. Configs are the building blocks blends and sessions consume.
- **Result object**: the typed return of a multi-output visualization (e.g. slope + aspect; SVF + anisotropic SVF + positive openness). Never a dict.
- **Raster**: an in-memory raster read through the rasterio-backed I/O layer — array plus transform, CRS, and nodata. Inside the compute layer nodata is always NaN in float32; nodata values exist only at the I/O boundary.
- **Session**: the batch workflow object — a DEM plus a list of configs, run as read → compute → write with parameter-encoded output names. Replaces the legacy `DefaultValues.save_*` machinery.
- **Blend**: a stack of layers (visualization + normalization + blend mode + opacity) rendered bottom-up into one image. A **preset** is a shipped blend expressed in code (VAT, CRIM, e3MSTP, e4MSTP).
- **Stretch**: a typed min/max (value or percentile) specification mapping a float visualization onto 8-bit output. Each config carries a default stretch.
- **Golden master**: a reference output committed under `tests/golden/`, generated by the legacy library, that the rewrite must reproduce within `assert_allclose` rtol ~1e-7.
- **Legacy**: the pre-rewrite library, kept under `legacy/` on this branch until parity is proven, then deleted.
